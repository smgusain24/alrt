## Critical Integration Bugs

### 1. `events.py` UPSERT Parameter Mismatch (BLOCKER)

**Affects:** TRIG-01, TRIG-04, WA-01, WA-02, DC-01, TG-01

Phase 4 added `discord_webhook_url` and `telegram_chat_id` to `UPSERT_BY_EXTERNAL_ID` (8 params). `events.py` `_resolve_subscriber` still passes 6 params. asyncpg crashes on **every trigger call** using the `subscriber` inline object.

**Fix:** Add `None` for `$6` (`discord_webhook_url`) and `$7` (`telegram_chat_id`); shift `sub.data or {}` to `$8`.

### 2. DLQ Retry Missing Phase 4 Channels (BLOCKER)

**Affects:** RETRY-01, DC-03, TG-03

`notifications.py` `task_map` and `queue_map` only cover `email`/`slack`/`in_app`. Phase 4 dead-letter retries return HTTP 400.

**Fix:** Add `whatsapp`/`discord`/`telegram` entries to both maps.

### 3. UI Condition Operators Without Backend Handlers (MODERATE)

**Affects:** COND-01, COND-02

`ConfigPanel.tsx` exposes `ends_with`, `not_exists`, `greater_equal`, `less_equal`. `step_runner.py` has no handlers — conditions silently pass through.

## Broken E2E Flows

1. **Trigger with subscriber inline:** Crashes at `_resolve_subscriber` → never creates execution
2. **DLQ retry for Phase 4 channels:** Returns HTTP 400 for whatsapp/discord/telegram
